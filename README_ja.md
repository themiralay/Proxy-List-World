これは軽量なプロジェクトで、10分ごとに多数の無料プロキシサイトをスクレイピングし、正常に動作するかを確認した上で、整理されたプロキシリストを提供します。


> 最新のスクレイパーによるスキャンで**5049**個のプロキシが見つかりました。利用可能なプロキシは以下の通りです。

## 使用方法

希望するファイル形式をクリックし、URLをコピーしてください。


|ファイル|内容|件数|
|----|-------|-----|
|[data.txt](https://raw.githubusercontent.com/themiralay/Proxy-List-World/master/data.txt)|`ip_address:port` の形で1行ずつ区切られている|516|
|[data.json](https://raw.githubusercontent.com/themiralay/Proxy-List-World/master/data.json)|`ip, port`|516|
|[data-with-geolocation.json](https://raw.githubusercontent.com/themiralay/Proxy-List-World/master/data-with-geolocation.json)|`ip, port, geolocation`|516|
